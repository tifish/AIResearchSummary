这些结果支持文章的核心定位：GPT-6.1 Terra 的价值不仅是能力提升，也在于让高频电脑操作的成本更易承受。

视觉理解正在连接到实际操作

在 MMMU-Pro 上，GPT-6.1 Terra 在所有推理设置下均优于 GPT-5.6 Terra。它以更低成本，接近 GPT-6 Astra 和 GPT-6.1 Sol 的得分。

在 OSWorld 2.1 上，它以中等推理强度超过 GPT-5.6 Terra 的最佳成绩。每项任务成本也低得多。

这些结果把视觉能力的用途扩展到桌面任务执行，而不只是看懂图片。

安全能力同步加强，但仍需看清评测范围

GPT-6.1 Terra 在 Preparedness Framework 的网络安全领域达到 Critical 阈值。它保留了为 GPT-6 Astra 开发的保护措施。

据 OpenAI 评估，它比 GPT-5.6 Terra 更能遵守任务范围，也更倾向于如实说明限制和潜在阻碍。提示注入测试还显示了较强的抵抗能力。

文章提供的是测试中的表现，未给出这些安全改进的具体比例。

事实错误明显减少，编程能力提升也有边界

事实准确性的改善在低推理强度下尤其明显。编程成绩也显著上升，但文章仍将最复杂的编程任务推荐给 GPT-6.1 Sol 和 GPT-6 Astra。

让快速、强大的电脑操作能力服务于大规模应用

我们推出了 GPT-6.1 Terra。这是一款快速、高效的模型，融合了细致的视觉推理、精准的电脑操作，以及更清晰自然的写作能力。与 GPT-5.6 Terra 相比，它有了显著提升。它擅长处理工作日里常见的沟通和电脑任务，包括起草提案、解读技术图纸、填写表单和编辑视频。

Terra 继续推动我们各模型系列在成本与智能之间取得更好的平衡，在速度、能力和成本上提供了新的选择。它的标准 API 价格比 GPT-5.6 Terra 和 GPT-6.1 Sol 低 50%。这让开发者更容易将大量工作自动化，例如读取收到的发票，再把详细信息录入会计软件。在 ChatGPT Work 和 Codex 中，使用 GPT-6.1 Terra 可以让套餐额度支持更多工作。相同的使用额度能完成比 GPT-5.6 Terra 更多的任务。与 GPT-6.1 Sol 或 GPT-6 Astra 相比，能完成的任务数量则多得多。

从视觉理解到行动

我们使用 Agents’ Last Exam 测量了 GPT-6.1 Terra 的电脑操作能力。这项基准测试包含多种专业任务，例如将建筑图纸转成 3D 模型，以及逐镜头审阅一部动画影片，为修复团队制作带有时间码的记录。在中等推理强度下，GPT-6.1 Terra 的得分比 GPT-5.6 Terra 高 15 个百分点，成本约为其三分之一。它的表现甚至与 GPT-6 Astra 相当，而每个 token 的价格仅为后者的十分之一。在最高推理强度下，Terra 的 token 使用效率超过 Claude Opus 5.5 的三倍，每个 token 的价格则为其四分之一。因此，每项任务的成本约为后者的九分之一。Terra 的速度也快得多。它完成任务的速度超过 GPT-6 Astra 和 GPT-6.1 Sol 的三倍。

在视觉推理基准测试 MMMU-Pro 上，GPT-6.1 Terra 在每一种推理设置下都优于 GPT-5.6 Terra。它甚至以低得多的成本，取得了接近我们能力最强的前沿模型 GPT-6 Astra，以及 GPT-6.1 Sol 的分数。

OSWorld 2.1 测试 AI 智能体使用桌面应用完成多步骤任务的能力，例如根据技术图纸构建 3D 模型。在中等推理强度下，GPT-6.1 Terra 就超过了 GPT-5.6 Terra 的最佳成绩，而每项任务的成本仅为后者的一小部分。

事实准确性和编程能力大幅提升

今年，我们投入了大量资源，以减少模型产生的幻觉和事实错误。在我们内部使用易诱发错误提示进行的基准测试中，低推理强度下的错误率从 GPT-5.6 Terra 的 53.6% 降至 GPT-6.1 Terra 的 16.7%，下降了近 37 个百分点。在最高推理强度下，错误率下降了 18 个百分点，降至 4.3%。这一水平已接近 GPT-6 Astra 和 GPT-6.1 Sol 的错误率。

在软件工程方面，GPT-6.1 Terra 比 GPT-5.6 Terra 有了大幅提升。Terminal-Bench 4.0 测试编程智能体通过命令行解决问题的能力，例如修复一个在加载过程中出现布局偏移的网页。在最高推理强度下，GPT-6.1 Terra 能解决 50.3% 的任务。这个比例超过 GPT-5.6 Terra 已公布的 21.5% 成绩的两倍。对于最复杂的编程任务，GPT-6.1 Sol 和 GPT-6 Astra 仍是更好的选择。

Terminal-Bench-Science 0.1 测试智能体使用代码完成科研任务的能力，例如追踪延时摄影视频中的细胞分裂。在最高推理强度下，GPT-6.1 Terra 以更低成本超过了 GPT-6.1 Sol。它与 Opus 5.5 的分差在 5 分以内，估算成本却不到后者的五分之一。

安全与对齐

在让强大的 AI 变得更高效、更易获得的同时，我们也持续通过训练、测试和改进来完善防护措施。根据我们的 Preparedness Framework，GPT-6.1 Terra 在网络安全领域达到 Critical 阈值。它也保留了为 GPT-6 Astra 开发的保护措施。

GPT-6.1 Terra 继承了 GPT-6 系列在对齐方面的改进。根据我们的评估，与 GPT-5.6 Terra 相比，GPT-6.1 Terra 更倾向于遵守任务范围，并向用户如实说明自身限制和潜在阻碍。在提示注入测试中，GPT-6.1 Terra 也表现出较强的抵抗能力。此类恶意指令旨在让模型偏离用户的任务。更多细节见系统卡（在新窗口中打开）。

定价与可用性

从今天起，ChatGPT Work 和 Codex 中的所有 Plus、Pro、Enterprise 和 Edu 用户都可以使用 GPT-6.1 Terra。开发者也可以通过 OpenAI API 使用它，模型名称为 gpt-6.1-terra。

标准 API 定价为：每百万输入 token 1 美元，每百万缓存输入 token 0.05 美元，每百万输出 token 5 美元。
