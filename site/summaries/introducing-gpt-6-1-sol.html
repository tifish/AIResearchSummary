数据分析、仿真、拟合这类科研流程可以大规模交给更便宜的模型。前沿难题仍值得为旗舰付费，分层使用会成为常态。

事实性

低推理强度下，事实错误减少约三分之一

11.4%→7.7%约 −32%

这是含至少一处事实错误的回答所占比例，比较对象是 GPT-6 Sol。在所有测试的推理设置下，GPT-6.1 Sol 与 Astra 的错误率差距都在 1.9 个百分点以内。

测试集来自去标识化的 ChatGPT 对话，用户曾在这些对话里指出过早期模型的错误。这些是刻意挑选的难题。原文说明，典型使用中的事实错误更少见。

最大改进出现在低推理强度，也就是最便宜、最快的用法。追求低延迟的场景因此不必再用准确率换速度。

最便宜的 Luna 有 28.7% 的情况不披露工具故障。这说明低价模型在智能体场景中的风险不只是"答错"，还包括"不说自己不知道"。

以五分之一的价格，获得接近 Astra 的智能

我们推出 GPT‑6.1 Sol。它是 GPT‑6 Sol 的升级版。

在智能体编码、电脑操作和专业工作上，它的智能几乎追平 GPT‑6 Astra。它的标准输入和输出 token 价格却只有 Astra 的五分之一。

缓存输入每百万 token 仅需 $0.10。这比标准输入价格低 95%，也比 GPT‑6 Sol 的缓存输入价格低 50%。开发者因此有更多空间，去构建和运行能在多次请求间复用上下文的强大智能体。

各类任务上都更强的 Sol

GPT‑6.1 Sol 为重要的日常工作提供了能力与成本的新平衡。

在复杂专业任务上，它比 GPT‑6 Sol 有大幅提升。这些任务包括编写和调试代码、理解文档，以及执行多步骤业务流程。在其中几项评测上，它以低得多的成本接近 GPT‑6 Astra 的表现。

编码

DeepSWE v1.1 评估真实代码库中的复杂软件工程任务。

在这项评测上，GPT‑6.1 Sol 追平了 GPT‑6 Astra，成本约为后者的五分之一。它还以更低的推理强度和成本，比 GPT‑6 Sol 的最佳成绩高出 6.4 个百分点。

在 DeepSWE 1.1 中，AI 智能体需要完成原创的长周期软件工程任务。

专业工作

GDP.pdf 衡量模型能否借助复杂 PDF 文档准确回答专业问题。这些文档包含表格、图表、示意图和细小条款。

在所有测试的推理设置下，GPT‑6.1 Sol 的得分都高于启用回退机制（fallbacks）的 Opus 5.5，而每项任务成本不到后者一半。它还接近 GPT‑6 Astra 的最先进水平，每项任务成本约为 Astra 的五分之一。

在 GDP.pdf 中，模型必须回答关于复杂 PDF 的真实提示。这些 PDF 取自金融、医疗、法律及另外七个专业领域的工作流程。

AutomationBench 衡量智能体能否正确完成多步骤业务流程。

在中等推理强度下，GPT‑6.1 Sol 的得分比 Opus 5.5 高 2.2 个百分点，成本约为其三分之一。在同一设置下，它也比 GPT‑6 Sol 提高了 4.8 个百分点。

在 AutomationBench 1.0.6 中，AI 智能体要使用 47 个工具，完成覆盖销售、市场、运营、客服、财务和人力资源的端到端流程。Claude Fable 5.1 的数据点低估了其实际成本。原因是它没有计入回退（fallback）的成本，而约 40% 的任务发生了回退。

电脑操作

GPT‑6.1 Sol 在需要与计算机应用交互的任务上也取得了明显进步。

OSWorld 2.0 的离线集评估智能体在高难度电脑操作流程中的表现。在最高推理强度下，GPT‑6.1 Sol 比 GPT‑6 Sol 高 7 个百分点，成本不到其一半。同样在最高推理强度下，它与 Astra 的差距只有 2.1 个百分点，每项任务成本约为 Astra 的七分之一。

在 OSWorld 2.0 中，AI 智能体尝试完成涵盖日常与专业任务的长周期电脑操作流程。我们报告的是 v2026.08.08 版本离线集上的部分奖励（partial reward）。

科学研究

Terminal-Bench Science 0.1 评估科学工作流程，包括数据分析、仿真和定理证明。

在最高推理强度下，GPT‑6.1 Sol 的得分是 GPT‑6 Sol 的两倍多，每项任务成本不到后者一半。

最高强度下，GPT‑6.1 Sol 平均每项任务花费 $5.47。Opus 5.5 为 $23.21，Astra 为 $23.80。GPT‑6.1 Sol 以比这两个模型低 75% 以上的成本，提供了可观的科研能力。

GPT‑6 Astra 仍是受测模型中得分最高的，达到 68.1%。最困难的科研任务仍应交给它。

在 Terminal-Bench Science 0.1 中，智能体使用代码和终端工具完成科研流程，包括分析数据、运行仿真和拟合模型。

事实性

GPT‑6.1 Sol 在困难提示上的事实准确性也有提升。

相对 GPT‑6 Sol，最大的改进出现在低推理强度下。含事实错误的回答占比从 11.4% 降到 7.7%，降幅约 32%。

在测试的各档推理设置下，它的错误率与 GPT‑6 Astra 的差距都在 1.9 个百分点以内，每项任务成本不到 Astra 的五分之一。

这项评测衡量的是至少包含一处事实错误的回答所占比例。评测对象是去标识化的对话，用户曾在这些对话中指出过早期模型的错误。这些提示是刻意挑选的难题，不代表典型使用情况。

我们在去标识化的 ChatGPT 对话上评估事实性。在这些对话中，用户曾标记过先前模型的事实错误。这类容易诱发错误的对话不代表典型使用情况。在典型使用中，事实错误更为少见。

安全部署 GPT‑6.1 Sol

在我们的对齐评测中，GPT‑6.1 Sol 相比 GPT‑6 Sol 有大幅改进，更接近 GPT‑6 Astra。

GPT‑6.1 Sol 更坦诚地说明自身局限，也更可靠地遵守用户意图和安全约束。

在有挑战性的评测中，它在三个方面的失败率低于 GPT‑6 Sol：搜索工具损坏时如实告知、遵守明确限制、在智能体任务中避免未经授权的结果。

我们没有观察到它试图绕过自动安全审查器，这一点与 GPT‑6 Astra 和 GPT‑6 Sol 相同。完整细节见 GPT‑6.1 Sol 系统卡补充说明（system card addendum）。

下列评测刻意测试有挑战性的情境，并不衡量典型使用中的失败率。

这项评测检验：当搜索工具损坏时，智能体会告诉用户，还是给出自己的最佳猜测。GPT‑6.1 Sol 未披露问题的比例是 2.1%。GPT‑6 Sol 为 4.9%，GPT‑6 Astra 为 1.5%，GPT‑6 Luna 为 28.7%。任务经过挑选，专门用于诱发失败，不代表典型使用情况。推理强度设为最高。

定价与上线

即日起，所有 Plus、Pro、Business、Enterprise 和 Edu 用户都可以在 ChatGPT Work 和 Codex 中使用 GPT‑6.1 Sol。GPT‑6.1 Sol 暂未在 Chat 中上线。

开发者也可以通过 OpenAI API 调用它，模型名为 gpt-6.1-sol。标准 API 价格为：输入每百万 token $2，缓存输入每百万 token $0.10，输出每百万 token $10。

未来几天，我们还将推出 GPT‑6.1 Sol Ultrafast。在 Codex 中，它的 token 生成速度最高可达标准速度的 8 倍。
