最值得带走的洞见

  • 速度提升服务于迭代。更短的生成等待，让尝试多个版本和细修素材更方便。
  • 一致性是多轮编辑的核心价值。角色、产品和品牌细节能否保留，会影响素材能否继续用于实际项目。
  • 质量和复杂度是两种控制维度。简单修改不必默认投入较高的规划强度。
  • GIF 与 SVG 扩展了交付形式。前者增加动态表达，后者衔接网站、应用与印刷用途。

我们正在 ChatGPT、Codex 和 API 中推出 Images 2.6，让你的创意更快成为现实。你可以借助 GIF 让图片动起来。无论是让品牌吉祥物或角色活动起来，还是把产品照片变成吸引眼球的循环动画，都能实现。你也可以更快制作精致的视觉作品，并进行更精准的调整。在编辑过程中，角色、产品和品牌细节能够保持一致。

如今，世界各地的用户每周通过 ChatGPT、Codex 和 API 创建 40 亿张图片。平均每天超过 5 亿张。

更快迭代，打造更专业的视觉作品

Images 2.6 的图像生成速度比此前快 50%。我们在 API 中提供 GPT‑Image‑2.6 Flare 和 Sunburst，供开发者选择。将 quality 设为 low 时，Flare 最快可在 6 秒内生成图片。对于需要更多细节和更高精度的工作，GPT‑Image‑2.6 Sunburst 在 quality 设为 medium 或 high 时，可以生成更高质量的图片。它还能在多轮编辑中更好地保持图像一致性。Flare 也提升了海报、产品图和其他专业视觉作品的布局质量。

用 GIF 让创意动起来

当你需要动态效果时，GIF 能为创意增加一个维度。营销人员和创作者可以让品牌吉祥物动起来，用于营销活动。他们也可以为社交媒体制作表情和梗图，或在视频制作前借助动画分镜探索角色动作。

严格使用 6 个连续画面，精确排列成 3 列、2 行的网格。阅读顺序为先从左到右，再从上到下。每个画面的尺寸完全相同。

在 API 中以更多方式创建和编辑

00:00

借助 Images 2.6，开发者可以更好地控制图像的创建、编辑，以及如何将图像用于项目的下一阶段。ChatGPT 已经提供的图像标注功能，现在也进入了 API。团队可以准确指出需要修改的位置和内容。SVG 导出则让设计可以直接用于网站、应用和印刷。

新的 complexity 参数允许开发者调整模型为完成请求所投入的规划程度。较低的设置适合快速编辑。图像质量控制视觉细节和保真度，而 complexity 则引导模型为场景构建投入多少工作。

“GPT‑Image‑2.6 将速度与创作控制力结合起来。它帮助你生成和编辑图片，同时保留体现角色、产品或品牌特征的细节。我们很高兴将它加入 Figma Weave，让团队在可复用的工作流中，再获得一个用于创意制作的强大模型。”

对于大多数编辑任务，我们建议使用 low complexity，以加快编辑速度。图像质量则根据工作流的需要选择。对于包含许多元素或约束条件的场景，可以尝试 medium 或 high complexity。
