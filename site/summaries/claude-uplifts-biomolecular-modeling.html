Claude 如何提升生物分子建模能力

How Claude is uplifting biomolecular modeling

一句话总括：Claude 优化了科学家已在使用的生物模型，让结构预测和蛋白质设计所需的计算资源显著减少，同时揭示了“能计算更大的系统”与“能准确预测更大的系统”之间的差距。

来源：Anthropic · 分类：Science · 原文页面

30 多个不到四周完成优化的开源模型数量，覆盖结构预测、蛋白质设计、蛋白质语言建模和基因组学。
约 4 倍仅损失极少数值精度时的平均提速；保持输出完全相同时，整体平均提速接近 2 倍。
约 150 美元GPU 与 token 合计花费，即可达到此前设计实验相近的计算机模拟表现。

收益来自底层计算和模型代码的共同优化

Claude 开发了 FlashPairformer，优化结构预测中的三角注意力和三角乘法。它还针对各模型缓存重复计算，并简化结果恒定的无效分支。通用内核与逐模型优化共同发挥作用，降低了现有科学工具的使用成本。

两位具有生物分子建模经验、但没有推理优化或内核工程经验的技术人员监督了这项工作。结果表明，AI 的科学价值也可以来自加快工具工程，让专业优化更容易完成。

内存门槛下降，准确性边界依然存在

超过 10,000 个 token：有准确预测实例

Big 模式可在单个 NVIDIA GPU 节点上准确建模超过 10,000 个 token 的系统。复合物 I 和 70S 核糖体都超过这一规模。

作为对照，原文提到 AlphaFold3 准确预测的 40S 核糖体含 7,663 个 token。更省内存的推理让更大的分子机器进入可建模范围。

超过 70,000 个 token：运行成功，结构不正确

在单个配备 8 块 GPU 的 B300 节点上，模型完成了规模从超过 31,000 到超过 70,000 个 token 的预测。

这些系统比训练上下文大近两个数量级，但预测结构发生塌缩。计算容量的扩展尚未带来同等幅度的泛化能力。

这里的 token 包括氨基酸、核苷酸，以及小分子和离子中的原子。“单节点”不等于“单 GPU”。

这使支持范围从计算工具延伸到实验验证，有助于检验效率提升能否转化为实际的分子设计成果。

最值得带走的洞见

  1. 科学工具本身也是 AI 的重要应用对象。此次贡献主要是改进已有模型的推理效率，让同一类研究更容易开展。
  2. 加速倍数必须连同条件一起读。少量精度损失与输出完全相同，是两种不同设置；整体模型与结构预测子集也不能混为一谈。
  3. 内存优化拓宽了可计算范围。但超大系统的错误预测说明，运行规模不能替代准确性证据。
  4. 模拟成本下降只是验证链条的一环。相近的 ipSAE 评分很有意义，真正的结合表现仍需湿实验检验。

完整译文

本文介绍 Claude 如何让科学家用于预测和设计生物分子的开源模型运行得更快、更省内存。在 Claude Science 中工作的 Claude，用不到四周优化了 30 多个模型，平均提速约 4 倍。它还创建了一种低内存模式。该模式可在单个 NVIDIA GPU 节点上，准确预测超过 10,000 个 token 的生物分子系统。这里的 token 包括氨基酸、核苷酸，以及小分子和离子中的原子。我们将开源全部优化代码，并宣布与 Adaptyv Bio 联合赞助一项蛋白质设计竞赛。竞赛将获得最高 100 万美元的 Claude 使用额度，并对超过 5,000 个设计开展湿实验验证。最近，我们公布了一项结果：Claude 能以专家水平统筹使用开源蛋白质设计和结构预测模型，从头设计蛋白质结合体。从头设计的结合体是通过计算设计的小型蛋白质。它们能够紧密结合特定靶分子，从而激活靶分子、阻断其作用，或将某种物质递送给它。

这项工作令人鼓舞地展示了 AI 的科学能力，也是推动药物发现的早期一步。不过，它消耗的资源超出了绝大多数蛋白质设计者的承受范围。我们允许 Claude 在 AI 基础设施平台 Modal 上，为每个靶点花费最多 10,000 美元。这大致相当于 2,500 NVIDIA H100 GPU 小时。

为了让更多人能够开展这类研究，我们开始探索推理优化，让这些模型运行得更高效。作为早期成果，Claude Mythos 5.1 加速了 7 个开源生物模型，使它们的运行速度最高达到原来的 2.5 倍。

本文介绍新的研究结果。一个内部通用研究模型成功优化了 30 多个深度学习模型。这些模型经过训练，可执行结构预测、蛋白质设计等多种生物学任务，也涵盖基因组学模型和蛋白质语言模型。Claude 只牺牲了极少的精度，就让这些任务平均提速约 4 倍。在输出完全相同的情况下，平均提速也接近 2 倍。Claude 还提高了这些模型的内存利用效率，使预测前所未有的大规模生物分子系统成为可能。我们将这些成果与此前智能体式蛋白质设计方法的简化结合起来。结果表明，Claude 所需的 GPU 小时数减少了两个数量级，仍能达到与此前报告结果相近的计算机模拟表现。

除了蛋白质设计，分子生物学家也广泛使用这些专用生物模型，包括将其用于药物发现与开发。今天，我们将开源所有这些模型的优化代码（此处），供更广泛的社区使用。更多细节见技术报告（此处）。

为了进一步支持社区，我们还将与 Adaptyv Bio 联合赞助一项蛋白质设计竞赛。Adaptyv Bio 率先开展了开放式蛋白质设计竞赛。我们共同选出了 5 个具有挑战性的问题，它们处于当前能力的前沿。我们将与 Adaptyv 一起，在 Modal 和 Twist Bioscience 的慷慨支持下，提供最高 100 万美元的 Claude 使用额度、25 万美元的 Modal 计算额度，以及超过 5,000 个设计的湿实验验证。更多信息见此处，申请入口见此处。

加速蛋白质结构预测和设计模型

蛋白质结构预测要解决的问题是：仅根据蛋白质的氨基酸序列，确定其三维结构。蛋白质设计则是创建具有特定结构、功能或一组性质的蛋白质。这两类计算工具相辅相成，让科学家能够研究关键的生物分子过程，例如癌症如何形成。它们也让科学家能够创造有用的分子，例如可能靶向这些癌症的药物。

AlphaFold3、OpenFold3 和 Boltz-2 等现代结构预测模型，将大量运行时间和内存用在两种运算上：三角注意力（triangle attention）和三角乘法（triangle multiplication）。这两种运算作用于 token 三元组，使模型能够描述生物分子系统的几何结构。但它们的计算成本极高，因为运行时间和内存需求都随系统规模呈立方增长。系统规模扩大到 2 倍，所需时间和内存就增加到 8 倍；扩大到 3 倍，则增加到 27 倍。

编写计算内核（kernel）是降低这些成本的常见方法。内核是一类底层软件转换层，用于 GPU 等加速计算硬件。三角注意力和三角乘法十分重要，因此已有专门针对它们的内核开发工作。先有 NVIDIA 的 cuEquivariance，近期又有 NVIDIA 的 BioNeMo Inference Runtime（BioNeMo-IR）。

在我们优化结构预测模型推理的工作中，我们与 Claude 合作开发了 FlashPairformer。这是一组定制内核，可加速三角注意力和三角乘法。它达到了新的最佳水平。根据模型配置的不同，三角注意力的平均速度是领域标准方案的 2.7–2.9 倍，三角乘法则为 1.7–3.2 倍。

除了开发可跨模型使用的内核，我们还让 Claude 逐一处理各个模型，以完成更有针对性的优化。这些改动包括缓存那些被重复计算的结果，以及将无效分支简化为其固定输出。综合这些改进后，结构预测模型平均提速 4 倍。对于每个模型，我们都确认了 Claude 的加速版本不会影响下游任务的表现，例如结构预测表现。

通常，即使是经验丰富的工程师团队，也需要数周才能为一个模型完成这类优化。而且，这些工作往往无法直接用于其他模型。Claude 在两位 Anthropic 技术人员的监督下，用不到四周完成了 30 多个开源模型的加速。这些模型覆盖生物分子结构预测、蛋白质设计、蛋白质语言建模和基因组学。两位监督者具有生物分子建模经验，但此前没有推理优化或内核工程经验。我们的结果表明，前沿 AI 模型将帮助这一领域的其他研究者更快、更轻松地构建科学工具。

让超大生物分子系统的建模成为可能

除了让这些蛋白质结构预测和设计模型运行得更快，我们还要求 Claude 降低大型分子机器建模过程中的内存使用。细胞中的许多工作由这类系统完成。例如，核糖体负责制造蛋白质，呼吸复合物为细胞供能，分子伴侣帮助其他蛋白质折叠。每个系统都由数十个组分构成。它们的功能取决于这些组分如何组合和相互作用。预测如此大型系统的结构，通常需要大量计算资源。例如，推理可能需要分布在多个 GPU 节点上。这类资源是多数分子生物学家无法获得的。

Claude 创建了低内存的“Big”模式。只使用一个 NVIDIA GPU 节点，该模式就能准确建模超过 10,000 个 token 的系统，也能成功完成超过 70,000 个 token 系统的推理。这在此前是无法实现的。使用 Big 模式成功折叠的分子机器包括人类线粒体复合物 I、TRiC 分子伴侣复合物、一个蛋白酶体，以及一个细菌核糖体。每个预测结果都与实验测定的结构高度吻合。据我们所知，它们属于结构预测模型迄今准确折叠的最大结构之列。其中，复合物 I 和 70S 核糖体都超过 10,000 个 token。相比之下，AlphaFold3 准确预测的 40S 核糖体包含 7,663 个 token。

为了测试 Claude 优化的极限，我们要求它预测比此前任何已实现规模都更大的结构。在单个配备 8 块 GPU 的 B300 节点上，Claude 生成了完整病毒衣壳和蛋白质区室的结构预测。这些系统的规模从超过 31,000 个 token 到超过 70,000 个 token 不等，比这些结构预测模型的训练上下文大近两个数量级。它们的结构未能得到正确预测，这或许并不令人意外。不过，如今只需一个 NVIDIA B300 节点，就能开展这一规模的推理，门槛已经显著降低。这意味着，随着工具改进，研究者或许很快就能通过计算对越来越复杂的生物系统进行建模。

Claude 高效地从头设计蛋白质结合体

在此前的蛋白质设计工作中，我们给 Claude 提供了一份约 16,000 个词的提示词。提示词鼓励它使用子代理，并允许它在 24 小时内，为每个靶点在 Modal 上花费最多 10,000 美元，约合 2,500 NVIDIA H100 GPU 小时。这一次，我们让单个 Claude 模型使用一块 NVIDIA H200，并给予 24 小时的实际经过时间。它收到的提示词约有 1,100 个词，另有一份预装工具参考表。整个过程没有子代理，也没有人类引导设计。

我们让三个 Claude 模型——Mythos 5.1、Mythos 5 和 Opus 5——使用本文介绍的加速生物分子模型，针对 16 个靶点开展设计。我们用 ipSAE 为设计评分。这是一种计算机模拟评分，已有研究表明它对湿实验中的结合表现具有预测价值。在 16 个靶点上取平均后，三个 Claude 模型所生成设计的评分中位数和最高值，都达到了与此前 Mythos 5.1 设计实验大致相同的 ipSAE 水平。与此同时，GPU 小时数减少了约两个数量级。我们还计入了 Claude token 成本。结果发现，GPU 和 token 合计花费约 150 美元，就能达到与此前设计实验相当的计算机模拟表现。
