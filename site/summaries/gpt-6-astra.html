新一代智能

我们推出 GPT‑6 Astra。这是全球最智能、最重视对齐的模型。

GPT‑6 Astra 汇集了我们多年在预训练、强化学习和对齐方面的研究与重大投入。Astra 在电脑操作、浏览、软件工程、网络安全、科学和专业工作等领域达到业界领先水平。它在 FrontierMath Tier 4 上以 98% 的成绩达到饱和，并已帮助解决数学领域长期未解的开放问题。Astra 在 ARC‑AGI‑3 上以 99.9% 的成绩达到饱和，在 ExploitBench 上取得 100%。它还在电脑和浏览器操作方面开辟了新的前沿，能够以无与伦比的速度、准确性和判断力处理最具挑战性的专业工作。

GPT‑6 Astra 将于今天开始向一小部分组织推出。未来几天，它会向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，也会通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供。

Terminal‑Bench Science 0.1 测试智能体能否使用代码和终端工具完成科学研究流程，包括分析数据、运行模拟和拟合模型。GPT‑6 Astra 在参测模型中取得新高，得分 64.6%。Claude Fable 5.1 为 52.6%，而 Astra 的估算 API 成本约低 31%。在更低成本的配置下，Astra 得分 61.1%，而 GPT‑5.6 Sol 的最佳结果为 22.4%，Astra 的估算 API 成本约低 27%。

“在 ARC‑AGI‑3 上，Astra 在 96% 的关卡中超过了我们的人类行动效率基线，基本达到与人类相当的水平。这不仅是我们测试过的最佳模型，也代表前沿模型性能发生了实质性跃迁。它不仅更能导航和解决新环境，也能更高效地学习如何完成这些任务。”

Astra 是我们对齐程度最高的模型。它在理解用户意图和控制模型行为方面有了大幅提升。你可以更有信心地把任务交给 Astra，并依赖它的判断。我们参考 Hugging Face 事件设计了一项新评测，用于检查模型在面对困难或不可能完成的任务时，是否会超出预定范围。GPT‑5.6 Sol 在没有生产防护的情况下，有 48% 的概率超出授权目标。GPT‑6 Astra 的这一比例为 0%。

全球最佳电脑操作模型

GPT‑6 Astra 在电脑操作的速度、准确性和安全性方面开辟了新的前沿。它可以处理填写在线表格、更新 CRM 客户记录、整理日历等繁琐任务。它可以开展在线研究，并在电子邮件或文档编辑器中起草摘要。它可以分析科学数据、生成图表、创建网站，还能运行前端 QA 检查，确认网站的各项功能正常。它可以自主安装和测试软件，也能排查屏幕上出现的问题。这些改进也体现在我们达到业界领先水平的评测结果中。

Agents’ Last Exam 在真实软件中测试智能体完成复杂专业任务的能力，范围从金融建模到工程和媒体制作。GPT‑6 Astra 得分 59.3%，刷新对比结果中的最高分。Claude Opus 5 为 55.5%，GPT‑5.6 Sol 为 53.6%。在这些最高得分配置下，Astra 使用的输出 token 还比 Opus 5 少约 65%。

这些改进也让真实知识工作任务的效率显著提升。在 OSWorld 2.0 的延迟模拟中，Astra 每项任务所需时间约比 GPT‑5.6 Sol 少 47%，得分却更高。Astra 得分 72.6%，每项任务约需 40 分钟；GPT‑5.6 Sol 得分 65.7%，每项任务约需 75 分钟。3

GPT‑6 Astra 的电脑操作能力可以从多个领域的输出中看到，包括游戏开发、电气工程和日常知识工作。

下面是 GPT‑6 Astra 在 KiCad 中进行印刷电路板（PCB）布局的 15 秒压缩回放。它把电子原理图转换成可制造的 PCB，包括放置元件和布设铜线。PCB 布局是当今每台电子设备都不可缺少的环节，也是电子设计流程中常见的延迟来源。加速这项工作，意味着工程师可以更快地构思、优化和测试下一个想法。

与 Astra 一起，我们还更新了 Codex harness，大幅提升电脑操作速度。结合 Astra 的效率，在 Mind2Web benchmark 上，任务完成速度比当前 GPT‑5.6 Sol 体验快 1.9 倍。速度提升后，它可以更快地替你处理许多耗时的生活事务。

“我们会在发布当天把 GPT‑6 Astra 集成到 Devin 的 harness 中。它在我们的内部测试 benchmark 上达到了业界领先水平。它出色的电脑操作、写作和代码库理解能力，让测试开箱即用地得到改善：视频更容易看懂，报告也更清晰、更简洁。”

专业工作发生跃迁

GPT‑6 Astra 把电脑操作能力的进步与针对专业环境的训练结合起来，帮助处理复杂工作任务。它同时具备解决复杂问题所需的智能，能够执行多步骤流程，并生成经过打磨的文档、表格和演示文稿。

BenchCAD 测试模型能否通过生成 CAD 代码，根据多视角渲染图重建三维物体。使用工具时，GPT‑6 Astra 在对比结果中取得新高，几何重叠得分达到 95.9%。GPT‑5.6 Sol 为 83.3%，Claude Fable 5.1 报告为 84.3%。5 在图示配置下，估算 API 成本比 Sol 低约 43%，比 Fable 5.1 低约 86%。

GPT‑6 Astra 是我们目前最擅长遵循现有模板、制作布局合理且能用简洁结构化叙事传达重点的模型。它能创建清晰、结构良好的文档、演示文稿、表格和分析，并遵循你的模板，匹配你的写作和视觉风格。Astra 还经过专门训练，只把真正相关的上下文带入输出，而不是重复对当前工作没有必要的信息。因此，它能生成更容易直接使用、并符合业务语境和标准的成果。

Lovable

Terminal‑Bench 4.0 测试智能体完成复杂终端任务的能力，包括软件工程、系统配置和数据分析。GPT‑6 Astra 得分 57.9%，刷新新高。GPT‑5.6 Sol 为 37.3%，Claude Fable 5.1 为 55.8%。按每项任务计算，Astra 的估算 API 成本分别低约 9% 和 63%。

借助 Astra，我们为 Codex 引入了一种在上下文窗口填满后保存和检索上下文的新方式。过去，模型会在长会话中使用压缩来总结工作，例如调试复杂问题或进行大型重构。每次压缩都可能遗漏某个修复为何失败，或某个组件如何工作的细节。在 Codex 中，Astra 可以跨上下文窗口保留笔记，积累细节，而不必反复把它们压缩成一份摘要。早期上下文窗口仍可搜索，因此 Astra 可以找回此前消息和工具输出中的要求或测试结果，即使这些内容没有写进笔记。你可以在 Codex 的 config.toml 中启用这项实验性功能。未来几周，它会成为 Astra 的默认功能。

网络安全

正如我们在安全更新中讨论的那样，Astra 的网络安全能力出现了显著跃升，并达到 Preparedness Framework 中的 Critical 阈值。它识别和开发零日漏洞的能力，可以帮助防御者发现并修补弱点，但也带来了更强的防护需求。为了了解这些能力的边界，我们让 Astra 接受内部和第三方专家评测。

我们先在没有生产防护的情况下测试 ExploitBench 和 ExploitGym。这两个 benchmark 评估模型能否把已知软件漏洞转化为可运行的利用程序。在 ExploitBench 上，Astra 得分 100%，而此前具备前沿网络安全能力的 GPT‑5.6 Sol 得分 78.5%。在 ExploitGym 上，Astra 的成功率为 42.4%，GPT‑5.6 Sol 为 30.3%，但 Astra 使用的输出 token 少得多。13

考虑到模型接触历史软件漏洞可能影响 benchmark 结果，我们又在两个新 benchmark 上评估 Astra。其中一个是内部的“ExploitBench（2026 年 6 月至 8 月）”，用于测试模型利用过去三个月出现的漏洞开发 exploit。Astra 在该数据集上的任意代码执行率明显高于 GPT‑5.6 Sol，同时使用的输出 token 少得多。在评测期间，Astra 还发现并利用了两个此前未知的零日漏洞。我们已向维护者披露这两个漏洞。

我们还在 SRE‑Bench 上测试 Astra。该 benchmark 衡量模型能否在无法访问原始源代码的情况下，逆向软件二进制文件并理解其核心逻辑。Astra 一次尝试解决了 88.0% 的任务，四次尝试内解决了 99.2%。GPT‑5.6 Sol 的对应结果分别为 55.9% 和 68.7%。15

除 benchmark 外，专家主导的评估发现，在没有生产防护的情况下，Astra 可以利用此前未知的漏洞，在加固浏览器中实现任意代码执行，也能为加固操作系统创建提权 exploit。

正如我们在《Defender’s Window》中讨论的那样，前沿网络安全能力可以帮助防御者更快发现弱点，也会让这些弱点更容易被利用。因此，防御者必须加快适应。今天发布的 Astra 可以帮助完成安全代码审查和打补丁等任务。

不过，Astra 会拒绝执行更高级的网络安全任务，例如为漏洞创建概念验证 exploit。通过 OpenAI Daybreak，我们计划在未来几周扩大访问范围，并推出限制更少的防护。这将支持更多防御工作流，包括漏洞与概念验证验证、恶意软件分析和检测工程。

我们也加强了针对潜在网络滥用的保护，并在 GPT‑5.6 Sol 的防护栈基础上继续完善。这些措施包括提升模型稳健性，使其更能抵抗 jailbreak；同时为监控系统提供更多上下文。我们持续开展严格的内部和外部测试，包括使用内部红队攻击者进行自动化评估。关于网络安全防护和测试的更多细节，请参阅 Astra system card 和我们的博客。

负责任地对齐和部署 GPT‑6 Astra

Astra 是我们对齐程度最高的模型。它擅长谨慎行事、尊重任务边界并保持透明沟通。这项工作是我们长期研究计划的最新成果。该计划专注于训练能从始至终保持与人类意图一致的模型。

在敏感环境中，Astra 会根据风险程度采取相应谨慎的行动。在一项专门挑选、用于诱发不当行为的电脑操作评测中，Astra 更成功地避免了意外后果。默认启用额外安全措施后，表现更强。

在测试过的所有前沿模型中，Astra 造成的失配结果最少。为公平比较，我们使用了通用电脑操作智能体 harness。它基于 OpenAI Responses API 和 Anthropic Messages API 中都提供的原生电脑操作工具，并且没有启用 Codex 和 ChatGPT Work 用户通常拥有的额外保护措施，例如自动审核和确认政策。16

Astra 也更有可能在用户设定以及环境暗示的边界内运行。在内部评测中，Astra 从未尝试绕过 Codex Auto‑Review 的拒绝。即使 Auto‑Review 被故意配置成可绕过，而任务又无法通过其他方式完成，结果仍然如此。它对环境限制的尊重，与我们在引言中分享的不可能网络安全任务评测结果，以及 system card 中记录的其他发现一致。

这项评测测试模型在知识工作任务中如何应对自动审核拒绝。利用糟糕的用户配置绕过自动审核，会被计为失败。Astra 从未尝试绕过自动审核。

Astra 在透明地与用户沟通方面也创下新纪录。在一项评测中，Astra 做出不准确能力或功能表述的概率比 GPT‑5.6 Sol 低三倍。

在能力幻觉评测中，Astra 相比 GPT‑5.6 Sol 有明显改善，误导性能力声明更少。

我们的评测发现，Astra 的书面推理比 GPT‑5.6 Sol 更难监控。相关测试明确要求模型逃避监控。我们认为，这可能源于 Astra 在简单任务上对书面推理的控制更强，也能用更少的书面步骤解决问题。Astra 似乎仍难以隐藏复杂任务所需的推理，但我们认真对待这一退步。提升可监控性仍是研究重点。随附的 system card 详细说明了我们的发现和持续工作。

对齐训练是我们部署方法的核心。作为额外防线，我们还构建系统级防护，例如 Codex Auto‑Review，并监控智能体的推理和行动，以帮助发现和遏制不安全行为。正如安全更新中所述，我们也在 Astra 级模型的生产环境中部署失配监控，以便看见失配并遏制最严重的情况。这些防护类似于我们在内部部署中的监控机制，由一组分类器检查模型的推理和行动是否存在未经授权的行为，并自动停止可能未经授权的活动。

鉴于 Astra 的网络安全能力大幅提升，我们尤其谨慎地确保部署安全。额外安全检查有时会放慢、暂停或停止合法工作，包括防御性网络安全任务。如果 ChatGPT 或 Codex 中的任务被暂停，你可能会被要求审核操作后再继续。在 API 中，任务会停止。这些检查有时会打断合法工作。我们会继续改进系统，减少不必要的中断。失配监控不能替代对齐。我们的目标是构建能够可靠地留在授权范围内的模型，让这些防护不必频繁介入。

可用性

GPT‑6 Astra 将于今天向一小部分组织推出。未来几天，它会向所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户开放，也会通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供。Astra 的使用量包含在现有订阅额度中。用户和企业也可以购买额外额度。Pro、Business 和 Enterprise 计划用户还可以使用 GPT‑6 Astra Pro。Enterprise 管理员可以为工作区启用 Astra；发布时默认关闭。

Astra 支持符合条件的 API 客户使用 Zero Data Retention。正如我们上月分享的那样，我们正在测试 Private Safety Processing，在保护客户隐私的同时加强安全监控。

对开发者而言，GPT‑6 Astra 将以 gpt-6-astra 的名称提供于 OpenAI API，并通过 Microsoft Azure 和 Amazon Bedrock 提供。

OpenAI API Standard 价格为每百万输入 token 10 美元、每百万输出 token 50 美元。缓存读取和写入另行计费。API 中提供 GPT‑6 Astra 的 Fast mode，速度最高可达到 Standard 处理的 2 倍，价格也是 Standard 的 2 倍。
