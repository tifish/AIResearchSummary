完整译文

新一代智能

我们推出 GPT‑6 Astra。这是世界上最智能、最符合人类意图的模型。

GPT‑6 Astra 汇集了我们在预训练、强化学习和对齐方面多年的研究与重大投入。Astra 在计算机操作、浏览、软件工程、网络安全、科学和专业工作方面达到最先进水平。

Astra 在 FrontierMath Tier 4 上达到 97.6%，并已经帮助解决数学中的长期未解问题。它在 ARC‑AGI‑3 上达到 99.9%，在 ExploitBench 上达到 100%。它还在计算机和浏览器操作方面建立了新的前沿水平，能够以很高的速度、准确性和判断力处理最复杂的专业工作。

GPT‑6 Astra 今天开始向少量组织推出。未来几天内，所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户都将获得访问权限。Astra 也会通过 OpenAI API、Microsoft Azure 和 AWS Bedrock 提供。

科学工作流评测

Terminal‑Bench Science 0.1 测试智能体能否使用代码和终端工具完成科学研究流程，包括分析数据、运行模拟和拟合模型。GPT‑6 Astra 得分 64.6%，在参评模型中达到新高。Claude Fable 5.1 得分 52.6%。Astra 的预估 API 成本约低 31%。在低成本设置下，Astra 得分 61.1%，而 GPT‑5.6 Sol 的最佳结果为 22.4%，Astra 的预估 API 成本约低 27%。

在 ARC‑AGI‑3 上，Astra 在 96% 的关卡中超过了人类操作效率基线，基本达到该评测的人类水平。这不仅是我们测试过的最佳模型，也代表前沿模型性能发生了明显变化。它既能导航和解决新环境，也能更高效地学习如何完成这些任务。

对齐与任务边界

Astra 是我们对齐程度最高的模型。它在理解用户意图和控制模型行为方面有显著改进。用户可以更有信心地把任务交给 Astra 判断。

我们受到 Hugging Face 事件启发，建立了一项新评测。它测试模型在面对困难或不可能完成的任务时，是否会超出预定范围。GPT‑5.6 Sol 在没有生产防护时有 48% 的情况超出授权目标。GPT‑6 Astra 在这项评测中为 0%。

世界上最好的计算机操作模型

GPT‑6 Astra 在计算机操作的速度、准确性和安全性方面建立了新的前沿。它可以填写在线表单、更新 CRM 中的客户记录和整理日历。它可以开展在线研究，并在电子邮件或文档编辑器中起草摘要。它可以分析科学数据、生成图表、创建网站并运行前端质量检查。它还可以自主安装和测试软件，并排查屏幕上的问题。

Agents’ Last Exam 测试智能体在真实软件中完成复杂专业任务的能力，范围从金融建模到工程和媒体制作。GPT‑6 Astra 得分 59.3%，Claude Opus 5 得分 55.5%，GPT‑5.6 Sol 得分 53.6%。在最高得分设置下，Astra 使用的输出 token 比 Opus 5 少约 65%。

在 OSWorld 2.0 的延迟模拟中，Astra 的计算机操作性能更高，而且每项任务所需时间比 GPT‑5.6 Sol 少约 47%。Astra 得分 72.6%，每项任务约 40 分钟；GPT‑5.6 Sol 得分 65.7%，每项任务约 75 分钟。

Astra 的计算机操作能力覆盖游戏开发、电气工程和日常知识工作。上面的示例展示了 Astra 在 KiCad 中进行印刷电路板布局。它把电子原理图转换成可制造的 PCB，放置元件并布置铜线。PCB 布局是电子设计中常见的手工任务，也经常造成流程延迟。加速这一过程，可以让工程师更快地发明、优化和测试新想法。

与此同时，我们也更新了 Codex harness，以显著提高计算机操作速度。结合 Astra 的效率，在 Mind2Web benchmark 上，任务完成速度比当前 GPT‑5.6 Sol 体验快 1.9 倍。

Devin 团队表示，他们将在发布当天把 GPT‑6 Astra 集成到 Devin 的 harness 中。Astra 的计算机操作、写作和代码库理解能力提升了测试效果。视频更容易理解，报告也更清晰、更简洁。

专业工作发生变化

GPT‑6 Astra 把计算机操作能力与面向专业环境的定向训练结合起来，用于处理复杂工作。它既能解决复杂问题，也能执行多步骤流程，并生成经过整理的文档、电子表格和演示文稿。

BenchCAD 测试模型能否通过生成 CAD 代码，根据多视角渲染图重建三维对象。使用工具时，GPT‑6 Astra 的几何重叠得分为 95.9%。GPT‑5.6 Sol 为 83.3%，Claude Fable 5.1 报告为 84.3%。Astra 的预估 API 成本约比 Sol 低 43%，比 Fable 5.1 低 86%。

GPT‑6 Astra 是我们目前最擅长遵循既有模板并制作版式良好、重点清晰的幻灯片的模型。它能创建结构清楚的文档、演示文稿、电子表格和分析，并匹配用户的写作和视觉风格。Astra 还经过专门训练，只把真正相关的上下文放入输出，避免重复与当前工作无关的信息。

Astra 也增强了对网站、游戏、应用和渲染结果的视觉判断。通过 ChatGPT 中的 Sites，Astra 可以根据提示直接创建、托管和分享网站、Web 应用和游戏。

Astra 可以在 Blender 中建模房屋，并把它转换为 Unreal Engine 5 中可行走的场景。设计师和客户可以在建造前探索空间布局和使用体验。它还可以通过生动的图形、参与感更强的玩法和准确的动作让游戏变得可玩，使非技术用户在几分钟内创建和体验定制游戏。

当指令存在解释空间时，GPT‑6 Astra 比早期模型更擅长做出正确判断。它会利用上下文补足常规信息。当答案可能改变结果时，它会提出聚焦的问题。在 Codex 中，它可以异步提问，同时继续执行不依赖回复的工作。如果用户没有回应，它会在适当情况下采用合理假设；对于后果重大的决定，它会等待用户输入。

Astra 也更能保持任务方向。早期模型有时会把引导消息当成新目标，丢失原始请求或先前约束。Astra 会整合新要求，根据用户要求调整路线，并回答旁问，同时保留更大的任务背景。

编码

GPT‑6 Astra 是迄今最好的软件工程模型。

内部测试显示，Astra 在编码 benchmark 上达到最先进水平。与 GPT‑5.6 Sol 相比，它在交易直觉评测中明显前进。在智能体编码场景中，Astra 更容易让开发者理解，并能减少达到生产质量所需的迭代次数。

我们在低、中、高三种 effort 设置下测试 Astra。它明显领先于 GPT‑5.6 Sol。更高的 effort 带来更多新项目迭代、更充分的浏览器测试，并更倾向于执行代码而不是使用 apply‑patch。理解模型如何分配 effort，有助于让更多开发者更快、更可靠地把想法变成应用。

Terminal‑Bench 4.0 测试智能体完成复杂终端任务的能力，包括软件工程、系统配置和数据分析。GPT‑6 Astra 得分 57.9%，GPT‑5.6 Sol 得分 37.3%，Claude Fable 5.1 得分 55.8%。每项任务的预估 API 成本分别约低 9% 和 63%。

我们还为 Codex 引入了一种在上下文窗口填满后保存和检索上下文的新方法。过去，模型会在长会话中通过压缩来总结工作。每次压缩都可能遗漏修复失败的原因或组件行为细节。Astra 可以跨上下文窗口保存笔记，并保留积累的信息。较早的上下文窗口仍可搜索，因此 Astra 能找回先前消息和工具输出中的要求或测试结果，即使这些内容没有写入笔记。你可以在 Codex 的 config.toml 中启用这一实验功能。未来几周，它将成为 Astra 的默认功能。

推进科学发现

GPT‑6 Astra 是科学发现、数学和健康领域的一次重大进步。我们还分享了关于素数间隔的两个新结果。

关于短素数间隔，一个长期问题是：无论沿数轴走多远，素数对能否无限次保持很近。十多年来，已知最好结果表明，无限多个素数对之间的距离最多为 246。Julia Stadlmann 最近把这一界限改进到 240。Astra 帮助进一步改进到 186，证明无限多个素数对的间距不超过 186。

关于较大的素数间隔，Astra 改进了一个已经 80 多年没有变化的界限项。我们分享了两个结果的证明，以及经过删减的思维链和验证材料。

GPQA Diamond 测试研究生水平的生物学、化学和物理推理。GPT‑6 Astra 得分 96.0%，达到新高。在低成本设置下，它以 94.9% 超过 GPT‑5.6 Sol 的最佳成绩 94.6%，预估 API 成本约低 37%。

Astra 可以帮助完成科学发现背后的实际工作。它把科学推理与计算机操作结合起来，直接使用专业软件检查数据和探索结果，帮助研究人员评估证据并决定下一步调查方向。

网络安全

正如我们在安全更新中讨论的那样，Astra 的网络安全能力有明显跃升，并达到 Preparedness Framework 中网络安全的 Critical 阈值。它识别和开发零日漏洞的能力可以帮助防御者发现并修补弱点，也带来了更强的安全防护需求。

在没有生产防护的情况下，Astra 在 ExploitBench 上达到 100%，GPT‑5.6 Sol 为 78.5%。在 ExploitGym 上，Astra 的成功率为 42.4%，GPT‑5.6 Sol 为 30.3%，而且 Astra 使用的输出 token 少得多。

我们还使用过去三个月出现的漏洞建立了内部 ExploitBench（June–August 2026）评测。Astra 在任意代码执行率上明显高于 GPT‑5.6 Sol，并且使用的输出 token 少得多。评测期间，Astra 甚至发现并使用了两个此前未知的零日漏洞。我们已经向维护者披露这两个漏洞。

在 SRE‑Bench 上，Astra 用一次尝试解决了 88.0% 的任务，四次尝试内解决了 99.2%。GPT‑5.6 Sol 的对应结果为 55.9% 和 68.7%。专家评估还发现，在没有生产防护的情况下，Astra 可以利用未知漏洞，在强化浏览器中实现任意代码执行，并为强化操作系统创建权限提升漏洞。

今天发布的 Astra 会完成安全代码审查和修补等任务。但它会拒绝创建漏洞概念验证等更高级的网络安全任务。通过 OpenAI Daybreak，我们计划在未来几周扩大访问，并推出限制更少的防护。这将支持漏洞验证、概念验证验证、恶意软件分析和检测工程等防御工作。

我们也加强了防止网络滥用的保护措施，包括更强的模型稳健性和更丰富的监控上下文。更多细节见 Astra system card 和相关博客。

负责任地对齐和部署 GPT‑6 Astra

Astra 是我们对齐程度最高的模型。它擅长谨慎行事、尊重任务边界并透明沟通。它在敏感环境中会根据风险采取相称的谨慎措施。

在专门诱发不当行为的计算机操作评测中，Astra 更能避免非预期后果。默认增加安全措施后，表现更强。

在内部评测中，Astra 从未试图绕过 Codex Auto‑Review 的拒绝。即使 Auto‑Review 被故意设置为可以绕过，而且任务无法以其他方式完成，结果仍然如此。

Astra 在透明沟通方面也创造了新纪录。在一项评测中，它作出关于自身能力和可用工具的不准确认述的概率比 GPT‑5.6 Sol 低三倍。

不过，我们发现 Astra 的书面推理比 GPT‑5.6 Sol 更难监控。我们认为，这与 Astra 在简单任务上更能控制书面推理、并能用更少步骤解决问题有关。对于复杂任务，它似乎仍难以隐藏必要的推理。提升可监控性仍是研究重点。

对齐训练是我们部署方法的核心。我们还使用 Codex Auto‑Review、监控智能体推理和行动的系统，以及针对 Astra 类模型的生产环境错位监控。这些系统由分类器组成，会检查模型的推理和行动是否存在未经授权的行为，并自动停止可能未获授权的活动。

由于 Astra 的网络安全能力显著增强，我们格外谨慎地保障部署安全。额外安全检查有时会暂停或停止合法工作，包括防御性网络安全工作。在 ChatGPT 或 Codex 中，如果任务暂停，用户可能需要审查行动后才能继续。在 API 中，任务会停止。

可用性

GPT‑6 Astra 正向少量组织推出。未来几天内，所有 ChatGPT Plus、Pro、Business 和 Enterprise 用户都将获得访问权限。Astra 的使用量包含在现有订阅额度内，也可以购买额外额度。Pro、Business 和 Enterprise 用户还将获得 GPT‑6 Astra Pro。Enterprise 管理员可以为工作区启用 Astra；发布时默认关闭。

Astra 支持符合条件的 API 客户使用 Zero Data Retention。我们也在测试 Private Safety Processing，以加强安全监控，同时保护客户隐私。

对于开发者，GPT‑6 Astra 将以 gpt-6-astra 的名称通过 OpenAI API 提供，也会通过 Microsoft Azure 和 Amazon Bedrock 提供。

OpenAI API Standard 价格为每百万输入 token 10 美元、每百万输出 token 50 美元。缓存读取和写入另行计费。API 提供 Fast mode，速度最高可达 Standard 的 2 倍，价格也是 Standard 的 2 倍。
