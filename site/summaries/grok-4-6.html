从回答问题走向持续完成项目

Grok 4.6 面向研究、信息分析和跨代码库开发等多步骤任务。测试中，它尤其擅长把宽泛的产品想法变成可运行的第一版。

相较 Grok 4.5，新模型生成的视觉和交互项目初稿更强。面对明确的产品构想，它可以一次建立应用结构和视觉语言。

今天，我们与 SpaceXAI 共同发布 Grok 4.6。

Grok 4.6 以 Grok 4.5 为基础，尤其关注长时间运行的智能体，以及更具挑战性的交互和视觉工作。无论是研究某个主题、分析信息、跨代码库工作，还是把一个想法变成完善的应用或工作成果，它都能持续处理包含许多步骤的复杂任务。

Grok 4.6 在多项智能体编程和知识工作基准中达到前沿水平。在由九项基准组成的 Artificial Analysis Intelligence Index 综合指数上，它追平了 GPT-5.6 Sol。

Grok 4.6 现已在 Cursor 和 Grok Build 中提供。第一周内，我们将在 Cursor 和 Grok Build 中提供 2 倍的使用额度。

Grok 4.6 的训练

与 Grok 4.5 相比，Grok 4.6 接受了时间更长的补充训练。训练内容包括为推理和高级技术概念精选的模型生成数据，以及高质量工程数据。团队还改进了优化器和训练方案。这些工作为随后的监督微调（SFT）和强化学习（RL）阶段奠定了更强的基础。

随后，我们使用 Grok 4.5 重新生成了 SFT 轨迹。这些轨迹覆盖不同的推理强度、智能体框架和专业领域，包括 STEM、软件工程和知识工作。我们通过基于模型的检查过滤了存在问题的轨迹。最终得到的 SFT 检查点展现出强劲的性能，行为表现也有所改善。

Grok 4.6 接受了广泛的智能体强化学习任务训练。其中包括知识工作和通用编程，也包括面向内核优化、Web 开发和计算机辅助设计等领域的专用环境。

把大胆构想变成可运行的项目

我们使用一组专门设计的项目测试 Grok 4.6。这些项目旨在拓展模型的能力范围，并检验它能否在许多步骤中持续工作。我们发现，这个模型尤其擅长把宽泛的产品构想变成可运行的第一版。它可以研究陌生领域，组织应用结构，实现核心交互，并根据多轮反馈继续完善结果。

在较长的执行轨迹中，我们也开始看到更多自我测试和验证行为。模型会先检查自己的工作，再继续下一步。

与 Grok 4.5 的典型表现相比，Grok 4.6 在视觉和交互项目上能产出更好的第一版。得到一个具体的产品构想后，它可以一次性建立应用的结构和视觉语言。因此，当获得良好结果的最快方式是先做出较完整的成果，再在反馈循环中持续迭代时，它会特别有用。

安全与能力

我们已经改进 Grok 4.6 的防护措施，并根据模型能力对其进行了校准。

我们的安全体系旨在让模型在合法使用场景中兼顾实用性与安全性。这让 Grok 4.6 能够安全地协助漏洞修补，加快工程设计周期，并增强 AI 研究能力。

针对 Grok 4.6 扩展后的能力，我们也相应调整了安全评估工作。模型接受了我们迄今范围最广的部署前能力测试和防护校准。部署后，我们还开展了广泛的第三方测试。

开始使用 Grok 4.6

Grok 4.6 现已在 Cursor 和 Grok Build 中提供。它也已登陆 SpaceXAI API，并通过 OpenRouter、Vercel 和 Cloudflare 等合作伙伴提供。
