进一步了解 Claude 的数学能力

从失败尝试到意外结果

Anthropic 员工让 Claude “认真尝试”证明黎曼猜想。这个问题自 1859 年提出，至今无人证明或否证，并设有 100 万美元奖金。

Claude 最终没有完成证明，但在探索过程中发现了一个相关结果。它把黎曼ζ函数位于临界线上的零点比例下界从 41.6% 提高到 67.2%。

这意味着 AI 的价值不只在于直接攻克目标，也在于探索目标周围的数学空间。

结果的边界

Anthropic 不认为 Claude 使用的技术能够证明黎曼猜想。新下界是相关进展，不是对猜想本身的解决。

两位 Anthropic 数学家审阅了论文。Brian Conrey 与 Dan Goldston 也在短时间内检查了工作。

为什么 67.2% 重要：数学家长期研究ζ函数零点，并逐步提高能够确认位于临界线上的零点比例。Claude 的结果把这一已知比例向前推进了一大步，但仍未回答“是否全部位于临界线”这一核心问题。

“即使 Claude 不能解决黎曼猜想，这一结果仍显示出 AI 模型数学能力的进步速度。”

这项成果是原始请求的非预期副产品，也是既有数学研究被重新组合后的产物。

规模化协作如何推动发现

Claude 在两次 Claude Code 会话中使用了总计 3100 万个输出 token。第一次生成并尝试了 650 个想法，全部没有奏效。

第二次持续了一天半。约 60 个 Claude 子代理运行了 2400 条 shell 命令，编写了数百个 Python 脚本，并对已知ζ零点执行数千次数值检查。它们还互相审阅工作。

Claude 随后让子代理寻找反例、下载 54 篇 arXiv 论文确认结果尚未被发表，并从头独立重做证明。Levent Alpöge 与 Ralph Furman 审阅了数学内容，Claude 则与 Eric Easley 合作完成 Lean 形式化，结果通过了标准验证工具 comparator。

洞见在于：人类主要提供目标和鼓励，模型负责大规模探索、筛选与验证。

完整译文

最近，Anthropic 的一名员工给 Claude 提出了一个不切实际的挑战：认真尝试解决数学界最著名的未解问题之一——黎曼猜想。

Claude 确实认真尝试了。但如果你了解这个问题的难度，就会预料到它没有成功。黎曼猜想可以追溯到 1859 年，并设有 100 万美元奖金。不过，在尝试过程中，Claude 意外地在一个相关问题上取得了进展。

Claude 的一个尚未发布的研究版本，改进了黎曼ζ函数零点中满足黎曼猜想的比例下界。借助数学家数十年来积累的大量研究，它把这一比例从 41.6% 提高到了 67.2%。

Anthropic 的两位数学家研究并验证了 Claude 的论文，还为专家撰写了一份非正式说明，简要陈述 Claude 的证明。Claude 也为自己的结果生成了一个可形式化验证的证明。我们感谢 Brian Conrey 和 Dan Goldston 两位该领域专家。他们在很短时间内审阅了这篇论文。

我们不认为 Claude 使用的技术能够导向黎曼猜想的证明。但这项工作成为 AI 模型数学能力快速进步的最新例子。下面我们讨论 Claude 如何处理这个问题，以及它发现了什么。

黎曼ζ函数

黎曼ζ函数描述了素数的分布：函数取零值的每一个位置，都会为素数序列贡献更精细的一层信息。黎曼猜想认为，决定素数分布的那些零点全部位于某条特定的竖直直线上。它已经成为数学中影响最深远的猜想之一。许多结果都假设它成立，以便为素数提供某种随机性形式。

至今没有人证明或否证黎曼猜想。但数学家沿着许多相关方向研究黎曼ζ函数及其零点，并取得了进展。其中一个方向就是量化位于这条直线上的零点至少占多少比例。随着研究推进，人们逐步把这个已知常数比例提高到了 41.6%。

另一个方向关注直线上的零点如何分布。1973 年，Montgomery 在这一领域提出了许多新技术，但这些技术假设黎曼猜想为真。近来，Baluyot、Goldston、Suriajaya 和 Turnage-Butterbaugh 等数学家发表了一系列工作，使 Montgomery 的技术无需这一假设也能运行。这意味着这些技术可以支持提高直线上零点比例的下界常数。Claude 的结果大量借鉴了这条研究路线，以及 Bombieri 在 2000 年发表的一篇论文。

Claude 的发现

Claude 发现，把 Baluyot、Goldston、Suriajaya 和 Turnage-Butterbaugh 的结果与 Bombieri 的工作结合起来，就能超过此前 41.6% 的最先进下界比例，将其提高到 67.2%。

下面是对 Claude 发现的简短技术说明：Claude 构造了一个合适的函数空间，其二次型由 Weil 诱导；同时构造了分别由位于直线之上和直线之外的零点产生的正定子空间与负定子空间。随后，Claude 根据一阶和二阶矩信息，写出了一个关于二次型秩的不等式。通过素数上的对偶图景，或通过控制 Hilbert 变换来成功计算后一个矩，这在解析数论中并不令人意外。真正推动结论成立的一步，在于 Claude 勇敢地处理整个空间，同时考虑正定性与负定性，并允许二次型是非对角的。

完整技术说明见论文。Claude 对其推导过程的解释见另一份附录。

Claude 的方法

Claude 的一个尚未发布的研究版本，在两次 Claude Code 会话中找到了新的下界，总计使用了 3100 万个输出 token。

Anthropic 员工 Jarred Sumner 并非数学家。他提示 Claude“认真尝试”黎曼猜想本身，之后把数学选择交给模型。起初，Claude 生成并尝试了 650 个想法，但没有一个奏效。Jarred 让 Claude 再试一次。Claude 这次花了一天半时间，协调约 60 个 Claude 子代理，探索得更加深入。它们合计运行了 2400 条 shell 命令，编写了数百个 Python 脚本。1 子代理针对已知ζ零点运行了数千次数值检查，还互相审阅工作。在整个过程中，Jarred 的主要作用是发送鼓励信息，大多是“继续努力”或“相信自己”之类的话。2 这似乎帮助 Claude 克服了最初对自己能否取得实质进展的怀疑。

发现新结果后，Claude 让多个子代理审阅证明、寻找反例、从 arXiv 下载 54 篇论文以确认这一发现尚未有人发表，并从头独立重新证明结果。Claude 主动提出把发现写成论文，并建议由人类数论专家验证。

Anthropic 自己的两位数学家 Levent Alpöge 和 Ralph Furman 研究了 Claude 的工作，以理解新结果及其与上述既有研究的关系。与此同时，Claude 与另一名员工 Eric Easley 合作完成了该结果的 Lean 形式化。形式化结果通过了标准验证工具 comparator。

AI 模型在数学领域的进展

这项结果表明，Claude 这样的 AI 模型可以延伸数学家思想的影响范围，并以新的、有时令人意外的方式发挥这些思想的作用。Claude 没有解决黎曼猜想，但这个结果却在尝试原始任务时意外出现了。

甚至 Claude 自己也对这一发现感到惊讶。它起初持怀疑态度，可能是因为训练数据让它了解数学开放问题的难度，也了解 AI 模型的局限。但在得到一些鼓励后，它得出了我们描述的结果。也许 Claude 和许多人一样，低估了 AI 进步的速度。
